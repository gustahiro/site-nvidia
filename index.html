Bibliotecas em ação

Vanta.js · efeito NET

Fundo interativo
com rede animada

O mesmo efeito também aparece no topo da página.

VANTA.NET({
  el: '#vanta-demo',
  color: 0x76b900,
  backgroundColor: 0x050800,
  points: 8,
  maxDistance: 20,
  spacing: 18
});

Vanilla-Tilt.js · inclinação 3D

DEMONSTRAÇÃO

Card interativo

Mova o cursor sobre este card para ver a inclinação 3D.

O mesmo efeito está nos cards de produtos; em telas táteis, eles permanecem estáticos.

VanillaTilt.init(
  document.querySelectorAll('.tilt-card'),
  {
    max: 5,
    speed: 400,
    glare: true,
    'max-glare': 0.12,
    scale: 1.02,
    perspective: 1000
  }
);

Coloris · seletor de cores

A cor selecionada atualiza os detalhes de destaque da página.

Coloris({
  el: '.coloris',
  theme: 'large',
  themeMode: 'dark',
  alpha: false,
  format: 'hex',
  swatches: ['#76b900', '#00a3ff', '#ff3d3d']
});

document.querySelectorAll('.coloris')
  .forEach(input => input.addEventListener(
    'input',
    event => document.documentElement.style
      .setProperty('--verde', event.target.value)
  ));
